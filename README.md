## The problem

Diners order from text and photographs and are routinely surprised by portion size and presentation. Restaurants carry the cost of that mismatch in returned plates and poor reviews.

## The approach

A multi-tenant SaaS where restaurants manage dishes and attach 3D models, and diners view them in augmented reality from a phone browser - no app install, since anything requiring a download will not be used at a table.

## Architecture

| Component | Responsibility |
| --- | --- |
| **Tenant management** | Per-restaurant menu administration |
| **Menu builder** | Dish, category and pricing management |
| **AR viewer** | Browser-based 3D and AR presentation |
| **Diner interface** | Mobile-first menu browsing |

## FAQ

### Do diners need an app?

No - AR runs in the phone's browser from a QR code or link.

### How do restaurants add dishes?

Through a management interface where each dish can carry a 3D model alongside its price and description.

### Is it multi-tenant?

Yes - each restaurant manages its own menu within one platform.
