# ARMenu - Augmented Reality Restaurant Menu SaaS - case study

**Engineer:** Muhammad Tanveer - Full-Stack AI Automation Engineer  
**Repository:** https://github.com/haddindeve/armenu-augmented-reality-menu-saas

## Context

Diners order from text and photographs and are routinely surprised by portion size and presentation. Restaurants carry the cost of that mismatch in returned plates and poor reviews.

## What I built

A multi-tenant SaaS where restaurants manage dishes and attach 3D models, and diners view them in augmented reality from a phone browser - no app install, since anything requiring a download will not be used at a table.

## Capabilities delivered

- Augmented reality dish preview
- No app install required
- Multi-tenant restaurant management
- Mobile-first diner experience

## Outcome

- Diners see true portion and presentation before ordering
- Delivered in-browser, removing the install barrier at the table
