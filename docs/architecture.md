# ARMenu - Augmented Reality Restaurant Menu SaaS - architecture

A multi-tenant SaaS where restaurants manage dishes and attach 3D models, and diners view them in augmented reality from a phone browser - no app install, since anything requiring a download will not be used at a table.

## Components

### Tenant management

Per-restaurant menu administration

### Menu builder

Dish, category and pricing management

### AR viewer

Browser-based 3D and AR presentation

### Diner interface

Mobile-first menu browsing

## Stack

| Layer | Technology |
| --- | --- |
| Frontend | React, TypeScript, Vite |
| Styling | Tailwind CSS |
| AR | Browser-based WebAR rendering |
| Architecture | Multi-tenant SaaS |
